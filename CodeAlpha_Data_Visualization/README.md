# YouTube Statistics Data Visualization Project

## Project Overview
This project performs data visualization and analysis on global YouTube statistics data using Python.

The project explores subscriber counts, channel categories, country-wise distribution, uploads, and video views through multiple visualizations and graphical insights.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Tasks
- Load and inspect YouTube statistics dataset
- Analyze channel and subscriber trends
- Visualize data using charts and graphs
- Identify patterns and insights from YouTube data
- Create graphical business and audience insights

## Features
- Top YouTube channel analysis
- Channel category visualization
- Country-wise channel distribution
- Subscriber and upload trend analysis
- Multiple data visualizations and insights

## Key Insights
- Some YouTube channels dominate subscriber counts globally.
- Entertainment and music channels are highly popular.
- Certain countries contribute more YouTube creators.
- Visualizations help understand audience and platform trends effectively.

## Conclusion
This project demonstrates how data visualization techniques can transform raw YouTube statistics into meaningful insights and trends using Python.
