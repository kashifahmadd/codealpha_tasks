# Twitter Sentiment Analysis Project

## Project Overview
This project performs sentiment analysis on Twitter data using Python and Natural Language Processing (NLP) techniques.

The project analyzes tweets and classifies them into Positive, Negative, or Neutral sentiments using the TextBlob library.

## Dataset Source
Twitter Sentiment Dataset from Kaggle:
https://www.kaggle.com/datasets/kazanova/sentiment140

## Technologies Used
- Python
- Pandas
- TextBlob
- Matplotlib
- Jupyter Notebook

## Project Tasks
- Load Twitter sentiment dataset
- Analyze tweet sentiments
- Classify tweets into sentiment categories
- Visualize sentiment distribution using graphs
- Generate insights from social media data

## Features
- Tweet sentiment classification
- NLP-based text analysis
- Sentiment distribution visualization
- Social media sentiment analysis

## Key Insights
- Twitter data contains mixed public opinions and emotions.
- Sentiment analysis helps identify audience reactions.
- Visualization makes sentiment patterns easier to understand.

## Conclusion
This project demonstrates how Natural Language Processing (NLP) techniques can be used to analyze public sentiment from social media platforms like Twitter.
