# Netflix Data Analysis Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Titles dataset using Python.

The analysis explores Netflix content trends, ratings, release years, and country-wise content distribution through data visualization techniques.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Tasks
- Data loading and inspection
- Data cleaning and missing value analysis
- Content trend analysis
- Visualization using charts and graphs
- Insight generation from Netflix data

## Features
- Movies vs TV Shows analysis
- Ratings distribution analysis
- Country-wise content analysis
- Release year trend visualization
- Data storytelling through visualizations

## Key Insights
- Netflix contains more movies than TV shows.
- Some countries contribute significantly more content.
- Most Netflix titles were released in recent years.
- TV-MA and TV-14 are among the most common ratings.

## Conclusion
This project demonstrates how Exploratory Data Analysis (EDA) and data visualization techniques can be used to identify trends and patterns in Netflix content data.
